# SkillHub

SkillHub is an iOS application developed using **Swift**, **UIKit**, and **Supabase** that allows users to connect by offering and requesting skills. Users can create skill posts, browse available skills, send skill requests, receive notifications, chat with other users, and manage their profiles.

---

## Features

- User authentication
- User profile management
- Upload and update profile pictures
- Create, edit, and delete skill posts
- Browse available skills
- Send and manage skill requests
- In-app notifications
- Private conversations between users
- Account deletion with complete data cleanup

---

## Technologies Used

- Swift
- UIKit
- Supabase
- Supabase Storage
- Xcode
- iOS SDK

---

## Requirements

- macOS
- Xcode 16 or later
- iOS 17.0+
- Supabase project

---

## Installation

1. Clone the repository.

```bash
git clone https://github.com/komikronsgit/SkillHub.git
```

2. Open `SkillHub.xcodeproj` in Xcode.

3. Configure your Supabase credentials in the project.

4. Build and run the application on a simulator or physical device.
